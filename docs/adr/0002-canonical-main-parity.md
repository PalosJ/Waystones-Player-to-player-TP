# ADR 0002：main 共享语义源与双向漂移门禁

- 状态：Accepted
- 日期：2026-08-12

## Context

`main` 必须永久保持 NeoForge 1.21.1 原设计，但共享修复还要进入两条统一 1.21.x 分支。仅依赖移植分支曾经成功的 CI 会让新 main 变更在旧绿灯后静默漂移。

## Decision

`main` 是共享语义源。统一分支记录最后同步的 canonical commit，并逐文件校验 pure core、网络契约和共享资源；`main` push 还主动获取并比较两个统一远端分支的当前共享文件。

## Consequences

- 共享文件改变后必须同步两个统一分支，才能恢复全绿。
- 只改变 main 专属适配或文档不会造成伪漂移。
- 分支基线提交记录是审计信息，不授权改写历史或强推。
