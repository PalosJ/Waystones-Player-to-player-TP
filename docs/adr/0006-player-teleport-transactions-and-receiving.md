# ADR 0006：玩家传送事务、个人接收与版本物品特性

状态：已接受，版本保持 1.0.1。此决策替代 ADR 0004 中固定 1 点损耗及仅同步入口的限制，并扩展 ADR 0002 的三分支范围至五条维护分支。

每名发送者只有一笔玩家传送事务，准备最长 200 个服务端 tick，提交前验证会话、原菜单／手／物品、目标接收、最终位置和费用。目标普通移动更新目的地并在需要时重新准备，不直接拒绝走动。提交后的结算只执行一次；位置和经验快照在实际消费前捕获。

26.x 使用实际可用的 Waystones 同步／异步与 Shogi API，完整读取默认规则和新版设置变量。保留适用原生传送石的蓄力、耐久规则、耐久开关、创造豁免和附魔处理，受控延迟损耗成功后结算。相邻位置优先，封闭时回退目标方块中心，不增加危险位置拒绝。

个人接收开关只放菜单，默认允许、按 UUID 保存到世界；关闭只限制传入，目录保留禁用行。协议升级为 2，双方即使都叫 1.0.1 也需同步更新。状态只附加已有玩家目录，不增加独立名单来源。

main 保持 NeoForge 1.21.1 的体验基线；两条 1.21.x 和两条 26.x 分支分别维护真实 API 差异。共享源码检查覆盖事务、协议、接收服务及测试，同系列比较适配族。代码相同不能代替逐目标玩法、GUI、性能和公开安装验收。
